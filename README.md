# csvSync（PWA）

「複数の明細をまとめて、家計簿に。」銀行・クレジットカードのCSV明細を、端末の中だけで統合する家計簿Webアプリです。CSVの内容を外部に送信しません。

## 中身

- `index.html` … アプリ本体（1ファイル）
- `manifest.json` … ホーム画面に追加するための設定
- `service-worker.js` … オフラインで開くための仕組み（アプリ本体のファイルだけを保存）
- `icon-192.png` `icon-512.png` `icon-maskable-512.png` `apple-touch-icon.png` … アイコン
- `check.html` … インストールできないときの診断ページ（確認が終わったら削除してかまいません）
- `.nojekyll` … GitHub Pagesで、そのままのファイルを公開するための空ファイル

## GitHub Pages で公開する手順

1. GitHubで新しいリポジトリを作る（名前は自由。例：`kakeibo`）
2. このフォルダの中身をすべて、リポジトリの直下にアップロードする（フォルダはありません。すべてのファイルを、フォルダに入れずに、そのまま直下に置きます。`.nojekyll` も含めます）
3. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存する
4. 数分待つと、`https://（ユーザー名）.github.io/（リポジトリ名）/` で開けるようになる

ファイルの場所は相対パスで書いてあるため、リポジトリ名が何でも動きます。

## Android へのインストール

1. Chromeで、公開したURLを開く
2. 右上の「︙」メニューから「アプリをインストール」（または「ホーム画面に追加」）を選ぶ

## 更新するとき

`index.html` などを直したら、`service-worker.js` の先頭にある `VERSION` の数字を1つ上げて、コミットしてください。古い画面が残るときは、アプリを完全に終了してから、開き直してください。

## プライバシー

- CSVの中身は、ブラウザの中だけで処理されます。サーバーには送られず、保存もされません（閉じると消えます）。
- 「この形式を保存」を押すと、名前と列の指定（見出しの文字、列の位置）だけが、お使いのブラウザの中に保存されます。CSVの内容は保存されません。「はじめから」を押しても、保存した形式は消えません。
- アクセス数の集計のため、GoatCounter（`wel-be.goatcounter.com`）の計測スクリプトを入れています。ページを開いたことが、GoatCounterに送られます。アプリがCSVの内容を送信することはありません。
- ページには、通信先を GoatCounter だけに限る設定（Content-Security-Policy）を入れています。計測をやめるときは、`index.html` の計測スクリプト（末尾の `data-goatcounter` の行）と、この設定の中の `gc.zgo.at` と `goatcounter.com` を消してください。
- 公開リポジトリには、**アプリのコードだけ**を置いてください。銀行・カードのCSV（テスト用を含む）や、個人情報が入ったファイルは、リポジトリに入れないでください。

## 注意

- Service Workerとインストールは、https（GitHub Pages）または localhost でだけ動きます。ファイルを直接開いた場合は、これらを使わない通常のアプリとして動きます。
- 銀行・カードの形式（列の指定）は、アプリの中で「この形式を保存」を押して登録します。保存先は、お使いのブラウザの中です。ブラウザのデータを消すと、保存した形式も消えます。保存した形式は、画面の一番下の「保存した形式」から、削除できます。

## インストールできないとき

公開したアドレスの末尾に `check.html` をつけて開くと（例：`https://（ユーザー名）.github.io/（リポジトリ名）/check.html`）、何が足りないかを、✔と✖で表示します。✖のところを、確認してください。

- アイコンや `manifest.json` が読み込めない → ファイルのアップロード漏れです。リポジトリの直下に、すべてのファイルがあるか、確認してください。
- アドレスが `https://` で始まっていない → インストールできません。GitHub Pages の公開アドレスで開いてください。
- ファイルをパソコンで直接開いたり、チャットのプレビューで開いたりしている場合は、アイコンやインストールは動きません。
